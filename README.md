# 오르카 런 (Orca Run)

라스트오리진 SD 대원으로 달리는 쿠키런 스타일 러너. SD 리그 런타임(`js/sd.js`)과 SD 데이터(`js/sd/`)는
`5_LAO_Defence`에서 가져왔고(원본 `E:/LAO_Google_QA/Assets`), 배경은 `AssetBundleResource/Texture/BGImg`를 잘라 씁니다.

## 실행

`run_server.bat` 더블클릭, 또는 `python tools/serve.py 8770` → http://localhost:8770

## 조작

- 점프: 화면 왼쪽 / Space / ↑ (공중에서 한 번 더 = 2단 점프)
- 슬라이드: 화면 오른쪽 누르고 있기 / ↓
- 일시정지: P / Esc

## 규칙

- 체력은 시간이 지나면 줄어듭니다. 하트로 회복, 적에게 부딪히면 -18, 구덩이에 빠지면 끝.
- 낮은 적은 점프, 큰 적은 2단 점프, 레이저 펜스(드론)는 슬라이드. 걸어오는 적과 발판 위의 적도 있습니다.
- 공중 발판(계단·상층 도로)에 올라 곰젤리를 노릴 수 있습니다.
- 젤리를 끊기지 않고 먹으면 콤보, 25콤보마다 점수 배율 +0.1(최대 ×2).
- **O·R·C·A** 글자 4개를 모으면 **보너스 타임**(8초, 장애물 없음, 점수 2배, 젤리 대형).
- 아이템: 하트·자석·부스트·거대화.
- 대원마다 스킬 게이지가 차면 자동 발동(컷인 + 슬로모션). 원거리 대원은 원작 탄환·피격 이펙트(`js/fx`, Defence에서 굽은 Unity 프리팹)로
  적을 격파하고, 스킬마다 원작 SD 모션(atk/skill)을 재생합니다. 상위 대원 스킬명은 원작 궁극기 이름(백화요란, NARAAK 미사일 등).
- 대원마다 고유 패시브(점프력, 받는 피해, 체력 감소, 젤리·격파 점수, 자석, 사거리, 아이템 시간, 보너스 시간 등).
- 500m마다 스테이지 변경(폐허 도심·해안 절벽·상업 지구·설원, 스테이지별 날씨).
- 결과 화면: 등급(S/A/B/C) + 대원의 원작 승리(win) 모션. 코인 = 주운 코인 + 거리 보너스 + 미션 보상.
- 미션 3개(완료하면 결과 화면에서 보상 후 새 미션), 코인으로 대원 29명 해금·강화(Lv.5까지: HP+10, 쿨타임 -6%, 지속 +8%/레벨).

## 개발

- `lineup.html?page=0..2` — 대원 SD 크기 비교(데이터의 `h`로 몸 크기를 맞춤)
- 콘솔 `GAME` — 상태 확인용(`GAME.setChar('hela')`, `GAME.startRun()`, `GAME.startBonus()`)
- 결정적 테스트: `GAME.hold(true)`로 루프를 멈추고 `GAME.step(프레임수, 1/60, 매프레임콜백)`으로 진행

## 셀프 테스트 (품질 측정)

`http://localhost:8770/?selftest=1` — 예측 봇이 실제 판을 플레이하고 항목별 점수를 화면에 표시합니다(약 5분).
옵션: `&ids=brownie,hela,...`(대원), `&frames=7200`(판당 최대 프레임, 60=1초). 플레이어 저장 데이터는 끝나면 원래대로 복원됩니다.

- 예측 봇: 매 프레임 점프 타이밍 약 120가지를 게임과 같은 물리·판정으로 1.2초 앞까지 시뮬레이션해 고릅니다.
  이 봇이 피하지 못한 피격·낙사 = 피할 수 없는 배치이므로 공정성 지표로 씁니다.
- 채점 기준은 `js/selftest.js`의 `score()`에 측정값·목표·배점으로 적혀 있습니다
  (이펙트·게임성·재미·그래픽·캐릭터 특성·원작 재현성).
